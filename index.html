PART 1: GOLDEN RULES & SUMMARY CHEAT SHEET Unit 1 & Unit 2
Unit 1: Laws of Powers & Exponential Equations Lessons 1 & 2
1. Power of a PowerIn × Out
$$(a^m)^n = a^{m \times n}$$
Ex: $(x^2 y^3)^4 = x^8 y^{12}$
2. Multiplying Same Base+ Powers
$$a^m \times a^n = a^{m + n}$$
Ex: $x^3 \times x^4 = x^7$
*Add: $2^a+2^a+2^a = 3 \times 2^a$
3. Dividing Same Base− Powers
$$\dfrac{a^m}{a^n} = a^{m - n}$$
Ex: $\dfrac{x^5}{x^3} = x^{5-3} = x^2$
4. Negative PowerFlip Base
$$\left(\dfrac{a}{b}\right)^{-n} = \left(\dfrac{b}{a}\right)^n$$
Ex: $\left(\dfrac{x}{3}\right)^{-2} = \left(\dfrac{3}{x}\right)^2 = \dfrac{9}{x^2}$
5. Distributing Power× and ÷ Only
$$(a \times b)^n = a^n b^n , \left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$$
Warning: Never distribute power over $+$ or $-$!
6. Negative Base $(-a)^n$3 Cases
• Even Power: Eats $(-)$ $\rightarrow (+)$
• Odd Power: Keeps $(-)$ $\rightarrow (-)$
• Zero Power ($a^0$): Always $= 1$
Exponential Eq. Case 1: Base = Base $\implies$ Power = Power
$$\text{If } a^x = a^y \implies x = y \quad (a \notin \{0, 1, -1\})$$
• Convert composite numbers into prime bases ($4 = 2^2, 8 = 2^3, 9 = 3^2, 27 = 3^3, 81 = 3^4, 125 = 5^3$).
• Reverse Split Trick: $2^{x+2} = 2^x \times 2^2$.
Exponential Eq. Case 2: When is Power = 0 ?Gift Rule
1) If RHS = 1: Equate the whole power to $0$.
   • Ex: $5^{x-3} = 1 \implies x - 3 = 0 \implies x = 3$.
2) Different Bases with Same Power: If $a^x = b^x \implies \text{Power} = 0$.
   • Ex: $5^{x+1} = 7^{x+1} \implies x + 1 = 0 \implies x = -1$.
Unit 2: Quadratic, Polynomial & Rational Functions Lessons 1, 2, 3 & 4
Quadratic Form 1: Standard Form$f(x) = ax^2 + bx + c$
• Vertex $(x, y)$: First find $x = \dfrac{-b}{2a}$, then substitute $x$ in $f(x)$ to get $y$.
• $y$-intercept: Directly at $(0, c)$.
Quadratic Form 2: Vertex Form$f(x) = a(x - h)^2 + k$
• Vertex $= (h, k)$ directly: Take $h$ (inside bracket) with opposite sign, and $k$ (outside) with same sign.
• Special Form: $f(x) = x^2 \pm k \implies \text{Vertex} = (0, \pm k)$.
Quadratic Requirement Rule / How to Find It Example: $f(x) = -(x - 3)^2 + 5$
1. Vertex & Axis of Symmetry Vertex $= (h, k)$  |  Equation of Axis of Symmetry is $x = h$. Vertex $= (3, 5)$  |  Axis: $x = 3$
2. Min. or Max. Value If $a > 0$ ($\cup$): Minimum $= k$  |  If $a < 0$ ($\cap$): Maximum $= k$. $a = -1 < 0 \implies$ Max. value $= 5$
3. $y$-intercept & $x$-intercept • $y$-intercept: put $x = 0$  |  • $x$-intercept (Roots): put $f(x) = 0$. $y$-intercept: $(0, -4)$
Intersects $x$-axis at 2 points $\rightarrow$ 2 Real Roots
Touches $x$-axis at Vertex $\rightarrow$ 1 Real Root
No Intersection with $x$-axis $\rightarrow$ $Z(f) = \varnothing$
Polynomial Condition & Real Zeros $Z(f)$Domain = $\mathbb{R}$
• Powers of $x$ must be non-negative integers $\{0, 1, 2, \dots\}$.
• NOT Polynomial: $x^{-n}$, $\sqrt{x}$, $\frac{1}{x}$, $2^x$.
• Shortcut: For $f(x) = x^2 + \text{positive number}$ (e.g., $x^2+9$), $Z(f) = \varnothing$.
Rational Function Rules $f(x) = \frac{\text{Num}}{\text{Den}}$
• Domain: $\mathbb{R} \setminus \{\text{Zeros of Denominator}\}$.
• Set of Zeros $Z(f)$: $Z(\text{Numerator}) \setminus Z(\text{Denominator})$.
• Common Domain: $\mathbb{R} \setminus \{\text{All zeros of all denominators without repetition}\}$.
Golden Order to Simplify Rational Functions: 1. Factorize (Num & Den) ➔ 2. Find Domain (BEFORE Canceling!) ➔ 3. Cancel Common Factors
Equivalence of Two Rational Functions ($f_1 = f_2$)
• $f_1 = f_2$ unconditionally if: 1) $\text{Domain } f_1 = \text{Domain } f_2$ AND 2) Simplest Form $f_1 =$ Simplest Form $f_2$.
• If Simplest Forms are equal but Domains differ $\implies$ Equal in the Common Domain.
Difference of Two Cubes ($x^3 - a^3$)
• $x^3 - 8 = (x - 2)(x^2 + 2x + 4)$  |  $x^3 - 1 = (x - 1)(x^2 + x + 1)$.
• Note: The big bracket $(x^2 + ax + a^2)$ never factorizes and has no real zeros!
